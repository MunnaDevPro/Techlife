How to Use

Endpoint

POST https://techlife.com.bd/api/blog/posts/

Authorization header

Authorization: Bearer techlife_user_YOUR_TOKEN_HERE

⚠ Must use HTTPS in production. Never share your token in public code.

Required request fields

Field Type Description
title * string Post title
description * string (HTML) Post body content (HTML is sanitized server-side)
category_slug * string Category slug (e.g. technology)
subcategory_slug string Optional subcategory slug
tags_list array Tag names e.g. ["AI", "tech"]
source_url URL Original article URL (used for idempotency)
source_image_url URL Remote image — safely downloaded & converted to WebP
original_content_hash string SHA-256 of your content (prevents duplicate submissions)

Fields marked * are required.

curl example

curl -X POST https://techlife.com.bd/api/blog/posts/ \
  -H "Authorization: Bearer techlife_user_YOUR_TOKEN_HERE" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "My Article Title",
    "description": "<p>Article body content goes here.</p>",
    "category_slug": "technology",
    "tags_list": ["tech", "tutorial"],
    "source_url": "https://yoursite.com/article/my-article",
    "source_image_url": "https://yoursite.com/images/hero.jpg"
  }'
