{% comment %} c-modal component Alpine-driven modal. Open via: $dispatch('open-modal', {id: 'my-modal'}) Close via: $dispatch('close-modal') or ESC. Props: - id: unique modal id (required) - title: modal heading text - size: sm | md (default) | lg | xl - static: true = don't close on backdrop click Slots: - body (default): modal content - modal_footer: action buttons area {% endcomment %}
